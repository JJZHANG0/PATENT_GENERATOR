# 康莱德工坊 专利申请材料生成器

为康莱德团队管理多个课题、分步填写申请资料并成套导出可编辑 Word 文书的网站。支持普通国内发明与实用新型申请材料，不覆盖外观设计及复杂特殊申请。

## 本地运行

在此目录执行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173/ 。无需安装依赖。

## 使用

1. 新建专利，填写队伍与专利类型。
2. 按六步填写人员、技术说明、权利要求、摘要并上传 PNG/JPG 附图。
3. 检查缺项，导出 Word 审阅/草稿 ZIP 包。
4. 在 Word/WPS 打开全部文件，核对信息、字体、图号、实际分页及签署要求。
5. 回填请求书的实际清单页数，导出归档包。

专利草稿与附图默认存储在当前浏览器的 IndexedDB。使用 AI 整理时，只有经你确认的上传材料、补充说明和已勾选的技术草稿会发送到后台与 OpenAI。不同网址和不同设备的数据不会自动同步。使用“备份专利资料”下载完整 JSON；“导入备份”将项目作为独立新记录添加，不覆盖原项目。备份包含填入的人员与技术资料，请妥善保管。

2026 年起，电子提交中的指定专利文件须转换为 XML 并由官方系统校验。本站输出用于编辑、审阅与归档的 Word 材料，不是电子提交完成证明。官方系统：https://cponline.cnipa.gov.cn/ 。

## Word 排版

请求书：从国家知识产权局 2025-12-31 发布的发明、实用新型请求书转换并建立字段槽位，保留表格和说明。填写行允许按内容增长，避免裁切。

正文：官方正文模板的页面与页眉页脚，A4 纵向，左上 25 mm、右下 15 mm，宋体 12 pt 黑色，固定行距 22 pt；说明书段号与权利要求编号自动编排，各文书独立页码。附图等比例适配、每图独立分页，另生成摘要附图。单独实审文件只对选择该项的发明项目生成。

页数由使用者在最终 Word/WPS 排版后核对填写，不估算。模板保留注意事项页，提交时按官方要求整理，不将无需提交的说明页计入实际清单。不同字体安装与文字处理软件可能影响最终分页。

## 验证

`node scripts/test-validation.cjs` 验证类型条件、摘要字数、权项引用、附图、备份输入等规则。

`qa/` 包含实际导出的发明与实用新型测试文书、渲染页图、模板来源及审计记录，只存在本地，不发布。`scripts/prepare_templates.py` 与 `dist/export.js` 为模板准备与 Word 导出实现。公开仓库不包含真实课题、个人资料、测试材料和浏览器备份。

## 网站源码

`dist/` 为部署目录；`dist/app.js` 负责填写与存储，`dist/export.js` 负责 Word 生成，`dist/templates/` 保存空白模板。JSZip 随站点打包，运行时不从第三方 CDN 加载脚本。GitHub Pages 通过 `.github/workflows/pages.yml` 自动发布 `dist/`。

## GitHub Pages

网站地址：https://jjzhang0.github.io/PATENT_GENERATOR/

推送到 `main` 后，GitHub Actions 先运行 JavaScript 语法检查和业务规则测试，再将 `dist/` 发布到 Pages。也可在 Actions 页面手动运行 Deploy GitHub Pages。

本站为公开网站。AI 功能接入 Supabase 后由队伍账号登录并检查成员权限、每日额度；专利草稿仍按账号保存在各自浏览器，不提供团队草稿云端同步。旧网站和 Pages 的网址不同，浏览器数据不会自动迁移：请从旧网站导出 JSON 备份，再在 Pages 里导入。不要将个人信息或真实课题备份提交到公开仓库。

空白模板已经随仓库提供，日常运行和部署不需要重新生成模板。`scripts/prepare_templates.py` 是维护用脚本，需要准备官方原始文件到本地 `qa/` 才能运行。

## 多文件 AI 专利整理

首页或专利编制页点击“AI 整理专利材料”，登录管理员分配的队伍账号后，可上传 1–8 份 PDF、DOCX、PPTX、TXT、MD 或图片。AI 整理九类专利技术字段，并列出来源线索、待补问题与类型建议。逐项审阅并勾选后才写入已有表单；已有内容默认不替换。

`dist/ai-config.js` 未配置后台时明确显示待接入，原有表单和 Word 导出保持可用。完整部署步骤、账号权限、密钥配置、数据处理范围见 [AI 部署说明](docs/AI部署说明.md)。OpenAI secret 只能放在后台，不能放在前端或公开 GitHub 仓库。

`node --test scripts/test-ai.mjs`（Node 22+）验证后台权限、文件输入、模型输出校验和安全采纳；测试使用模拟上游，不产生 OpenAI 用量。
